# BSI CX Design Documentation

This repository contains the _generated_ artifacts for the BSI CX design documentation. The repository does not contain the AsciiDoc source files, but only the generated artifacts to be hosted on github.io.

**Archive notice:** As of September 2026 the documentation for releases newer than 23.2 have been
converted to a new documentation build and moved [here](https://bsi-software.github.io/bsi-cx-design-docs).
Documentation for the older versions of BSI CX are archived in this repository and can be browsed 
[here](https://bsi-software.github.io/bsi-cx-docs/).
